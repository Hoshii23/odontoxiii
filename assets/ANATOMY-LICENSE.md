# Dental anatomy assets

**Anatomy from 3Dentes by Nate Saindon, CC BY-NC 4.0.**

- Source: https://github.com/NateSaindon/3Dentes
- License: https://creativecommons.org/licenses/by-nc/4.0/
- Original paths: `assets/cbct/stl/FMA55698{,-enamel,-pulp}.stl`,
  `FMA55681{,-enamel,-pulp}.stl`, `FMA55798.stl`, `FMA55689.stl`.
- Source describes the donor as the repository author and supplies consent for
  publication. These assets represent one individual's anatomy.
- Changes in odontoxiii: coordinate rotation, centering, scale normalization,
  0.0001 display-unit quantization, vertex welding, computed smooth normals,
  display colors, and an illustrative arch assembled from representative teeth.
- Outer tooth and pulp geometry are CBCT-derived. Enamel thickness in the source
  is an anatomical approximation derived from literature. The pulp was manually
  segmented. Small structures may be absent due to imaging resolution.
- These assets are provided for **noncommercial** educational use with credit.
  They are not covered by any license applying to the application source code.
- The reconstructed arch, gum, lesions, clinical states and instruments are
  educational illustrations, not measured anatomy of a simulated patient.
